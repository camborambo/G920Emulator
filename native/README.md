# Native packages

| Folder | Purpose |
|--------|---------|
| `winuhid\` | Bundled WinUHid runtime + INF (publish copies into `dist\SteeringWheelEmulator\winuhid\` and `WinUHid.dll` beside the EXE) |
| `emuffb\` | OEM DirectInput EffectDriver (`emuffb.dll`) used for virtual G920 / Fanatec DD1 FFB |
| `logisdk\` | Bundled Logitech Steering Wheel SDK runtimes (publish copies into `dist\SteeringWheelEmulator\logisdk\`) |

See each folder’s README for ownership / rebuild notes.
